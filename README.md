# Volt Ride

A first-person electric bike game that runs in the browser with Three.js. Three.js is bundled in `lib/`, so the game needs no internet to run.

Open `index.html` through any static server (for example GitHub Pages, or `python3 -m http.server`) and choose a bike and a spawn point.

**Controls:**
- W / S: throttle and brake
- A / D: steer
- Shift: wheelie
- Ctrl or Q: lean forward
- Space: rear brake
- C: change camera
- 1-8: switch bike
- N: switch between day and night
- Hold T: fast-forward time
- M: map
- R: respawn

On a touchscreen without a keyboard, buttons appear on the screen.
